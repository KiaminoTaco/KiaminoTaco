## 🚧 Current Work

### 🚄 RailGard — Autonomous TGV Undercarriage Inspection Robot

A robotics project focused on **automating railway undercarriage inspection**.

**System technologies include:**

- 🤖 ROS 2 robotics architecture
- 🧠 Raspberry Pi 4 for onboard computing
- 🔌 ESP32-based embedded control
- 📷 Camera-based inspection
- 📡 LiDAR & ultrasonic sensing
- 🌡️ Temperature monitoring
- ⚙️ Mechanical system design

> **Objective:** combine mechanical engineering, embedded electronics, sensing and robotics into an autonomous inspection platform.
